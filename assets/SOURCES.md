# Asset provenance

All project illustrations are taken from the author's existing public repositories.

- `tagent-flow-demo.png`: an unmodified frame at 02:25 from [TAgent's published Flow-plan demo](https://github.com/pengmoubuaixuexi/TAgent/blob/main/docs/demo-videos/05-%E6%B5%81%E7%A8%8B%E8%AE%A1%E5%88%92%E7%A1%AE%E8%AE%A4%E7%BC%96%E8%BE%91.webm). The recording uses an earlier UI version. It is a demonstration, not a newly measured production result.
- `srgcd-framework.png`: identical to [SRGCD/assets/framework.png](https://github.com/pengmoubuaixuexi/SRGCD/blob/main/assets/framework.png).
- `banner.svg`, `typing.svg`, `stack.svg`: original vector layout using Tao Peng's public identity and the projects' actual technical topics. No generated project screenshots or fictional research results.
- `github-stats.svg`, `languages.svg`, `public-data.json`: generated from public GitHub REST data by `scripts/update_stats.py`. Forks and this profile repository are excluded. Language proportions are based on code bytes returned by GitHub, not expertise or unpublished work. The observation time is stored with the data and printed on each card.

The images retain the attribution and usage terms of their respective source projects. This profile does not grant new rights to third-party research material.
